\section{Introduction}

Ce laboratoire pratique a pour objectif d'explorer les capacités de l'outil \textbf{Nmap} (Network Mapper) dans le cadre d'une stratégie de reconnaissance active. Suite à la détection d'une activité suspecte sur la machine 10.6.6.23 du réseau DMZ, nous avons été chargés d'effectuer une énumération complète pour identifier les services actifs et les vulnérabilités potentielles.

\begin{objectifbox}
\begin{itemize}
    \item Explorer les fonctionnalités de Nmap
    \item Effectuer des analyses de base et avancées
    \item Identifier les services vulnérables
    \item Détecter les problèmes de configuration de sécurité
\end{itemize}
\end{objectifbox}

\subsection{Environnement de laboratoire}

\begin{itemize}
    \item \textbf{Système d'analyse :} Kali Linux (10.6.6.0/24)
    \item \textbf{Cible :} Machine suspecte (10.6.6.23)
    \item \textbf{Réseau :} DMZ 10.6.6.0/24
    \item \textbf{Outil principal :} Nmap 7.93
\end{itemize}

\section{Partie 2 : Analyses Nmap de base}

\subsection{Découverte des hôtes actifs (Host Discovery)}

La première étape consiste à identifier tous les hôtes actifs dans le réseau DMZ.

\begin{commandbox}
\begin{lstlisting}
# Analyse de decouverte du reseau DMZ
nmap -sn 10.6.6.0/24
\end{lstlisting}
\end{commandbox}

\begin{resultatbox}
\textbf{Nombre d'hôtes actifs détectés :} 7 hôtes (incluant le système Kali Linux)
\end{resultatbox}

\begin{figure}[H]
    \centering
    \fbox{\includegraphics[width=0.80\textwidth]{screenshot_host_discovery.png}}

\subsection{Analyse des ports ouverts}

Nous effectuons maintenant une analyse par défaut sur la cible identifiée (10.6.6.23).

\begin{commandbox}
\begin{lstlisting}
# Analyse par defaut des 1000 ports TCP les plus courants
nmap 10.6.6.23
\end{lstlisting}
\end{commandbox}

\begin{resultatbox}
\textbf{Ports ouverts détectés :}
\begin{itemize}
    \item Port 21 (FTP)
    \item Port 22 (SSH)
    \item Port 53 (DNS)
    \item Port 80 (HTTP)
    \item Port 139 (NetBIOS-SSN)
    \item Port 445 (Microsoft-DS/SMB)
\end{itemize}
\end{resultatbox}

\begin{figure}[H]
    \centering
    \fbox{\includegraphics[width=0.80\textwidth]{screenshot_port_scan.png}}

    \label{fig:port_scan}
\end{figure}

\begin{definitionbox}{États des ports Nmap}
\begin{itemize}
    \item \textbf{Open :} Un service écoute sur ce port (réponse SYN-ACK)
    \item \textbf{Closed :} Aucun service n'écoute (réponse RST)
    \item \textbf{Filtered :} Port filtré par un pare-feu (pas de réponse)
\end{itemize}
\end{definitionbox}

\section{Analyse des services SMB}

\subsection{Scan initial des ports SMB}

Les ports 139 et 445 indiquent la présence du protocole SMB (Server Message Block).

\begin{commandbox}
\begin{lstlisting}
# Analyse des ports SMB avec scripts par defaut
nmap -A -p139,445 10.6.6.23
\end{lstlisting}
\end{commandbox}

\begin{resultatbox}
\textbf{Informations SMB détectées :}
\begin{itemize}
    \item Service : Samba smbd 4.9.5-Debian
    \item Groupe de travail : WORKGROUP
    \item Nom NetBIOS : 868CF29B394C
    \item Signature de message : désactivée (dangereux)
\end{itemize}
\end{resultatbox}

\subsection{Énumération des partages réseau}

Recherche de partages réseau publics ou mal configurés.

\begin{commandbox}
\begin{lstlisting}
# Enumeration des partages SMB
nmap --script smb-enum-shares.nse -p445 10.6.6.23
\end{lstlisting}
\end{commandbox}

\begin{resultatbox}
\textbf{Partages réseau découverts :}
\begin{enumerate}
    \item \texttt{\textbackslash\textbackslash 10.6.6.23\textbackslash IPC\$} (partage caché système)
    \item \texttt{\textbackslash\textbackslash 10.6.6.23\textbackslash print\$} (pilotes d'imprimante)
    \item \texttt{\textbackslash\textbackslash 10.6.6.23\textbackslash workfiles} (fichiers de travail)
\end{enumerate}
\textbf{Partages masqués :} 2 (IPC\$ et print\$)
\end{resultatbox}

\end{alertbox}

\section{Vulnérabilités identifiées}

\subsection{Risques de sécurité critiques}

Au cours de cette énumération, plusieurs vulnérabilités graves ont été découvertes sur la machine 10.6.6.23 :

\begin{enumerate}
    \item \textbf{Service FTP mal configuré}
    \begin{itemize}
        \item Accès anonyme autorisé sans authentification
        \item Fichiers sensibles accessibles publiquement
        \item Version vsftpd 3.0.3 (vérifier les CVE associées)
    \end{itemize}
    
    \item \textbf{Partages SMB non sécurisés}
    \begin{itemize}
        \item Accès anonyme en LECTURE/ÉCRITURE sur tous les partages
        \item Partage \texttt{workfiles} contenant des fichiers confidentiels
        \item Signature de messages désactivée (exposition aux attaques man-in-the-middle)
    \end{itemize}
    
    \item \textbf{Énumération facile des utilisateurs}
    \begin{itemize}
        \item Noms d'utilisateurs découverts sans authentification
        \item Facilite les attaques par force brute
    \end{itemize}
    
    \item \textbf{Services inutiles exposés}
    \begin{itemize}
        \item Plusieurs ports ouverts sans nécessité apparente
        \item Surface d'attaque élargie
    \end{itemize}
\end{enumerate}

\subsection{Recommandations de sécurité}

\begin{itemize}
    \item Désactiver l'accès FTP anonyme
    \item Configurer l'authentification forte sur les partages SMB
    \item Activer la signature des messages SMB
    \item Fermer les ports non essentiels
    \item Mettre à jour les services vers les dernières versions
    \item Implémenter un système de détection d'intrusion (IDS)
    \item Restreindre l'énumération des utilisateurs
\end{itemize}
