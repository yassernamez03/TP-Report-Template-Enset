\section{Introduction}

Dans ce TP, nous avons appris à créer notre propre image Docker à l'aide d'un Dockerfile, puis à automatiser l'orchestration d'un service web avec Docker Compose. Ce travail fait suite au TP précédent et permet de comprendre comment construire et déployer une application dans un environnement conteneurisé.

\section{Objectifs du TP}

Les objectifs de ce travail pratique sont les suivants :

\begin{itemize}
    \item Construire une image Docker personnalisée avec un Dockerfile
    \item Déployer un site web statique dans un conteneur Nginx
    \item Utiliser Docker Compose pour orchestrer et lancer le service automatiquement
    \item Vérifier le bon fonctionnement du site via un navigateur
\end{itemize}

\section{Partie 1 --- Préparation de l'environnement}

\subsection{Connexion à la machine EC2}

Pour commencer, nous nous connectons à notre instance EC2 via SSH :

\begin{lstlisting}
ssh -i "LINUX_TP3_DOCKER&COCKPIT.pem" ubuntu@ec2-44-197-209-236.compute-1.amazonaws.com

\section{Partie 2 --- Création d'une application simple}

\subsection{Création du dossier de travail}

Nous créons un dossier dédié pour notre projet :

\begin{lstlisting}
mkdir ~/tp5_docker && cd ~/tp5_docker
\end{lstlisting}

\subsection{Création du fichier index.html}

Nous créons ensuite un fichier HTML simple pour notre site web statique :

\begin{lstlisting}
nano index.html
\end{lstlisting}

Le contenu du fichier est le suivant :

\begin{lstlisting}[language=html]
<!DOCTYPE html>
<html>
<head>
    <title>TP5 - Conteneurisation</title>
</head>
<body style="text-align:center; font-family:sans-serif;">
    <h1>Bienvenue dans le TP5</h1>
    <p>Ce site tourne dans un conteneur Nginx personnalise !</p>
</body>
</html>
\end{lstlisting}

\section{Partie 3 --- Création du Dockerfile}

\subsection{Création du fichier Dockerfile}

Nous créons maintenant le Dockerfile qui définira notre image personnalisée :

\begin{lstlisting}
nano Dockerfile
\end{lstlisting}

Contenu du Dockerfile :

\begin{lstlisting}
# Etape 1 : Choisir une image de base
FROM nginx:latest

# Etape 2 : Copier le fichier HTML dans le conteneur
COPY ./index.html /usr/share/nginx/html/index.html

# Etape 3 : Exposer le port 80 pour l'acces web
EXPOSE 80

# Etape 4 : Lancer Nginx
CMD ["nginx", "-g", "daemon off;"]
\end{lstlisting}

\section{Partie 4 --- Construction et exécution de l'image}

\subsection{Construction de l'image Docker}

Nous construisons notre image Docker à partir du Dockerfile :

\begin{lstlisting}
docker build -t tp5_nginx:1.0 .
\end{lstlisting}

Puis nous vérifions la création de l'image :

\begin{lstlisting}
docker images
\end{lstlisting}

\subsection{Lancement du conteneur}

Nous lançons maintenant un conteneur basé sur notre image :

\begin{lstlisting}

\end{lstlisting}

\section{Partie 5 --- Orchestration avec Docker Compose}

\subsection{Création du fichier docker-compose.yml}

Pour automatiser le déploiement, nous créons un fichier Docker Compose :

\begin{lstlisting}
nano docker-compose.yml
\end{lstlisting}

Contenu du fichier :

\begin{lstlisting}[language=yaml]
version: '3'
services:
  web:
    build: .
    container_name: tp5_nginx
    ports:
      - "8080:80"
    restart: always
\end{lstlisting}

\begin{figure}[h]
\centering
\includegraphics[width=0.8\textwidth]{image8.png}
\caption{Fichier docker-compose.yml}
\end{figure}

\subsection{Lancement avec Docker Compose}

Nous lançons notre application avec Docker Compose :

\begin{lstlisting}
docker-compose up -d
docker ps
\end{lstlisting}

\section{Conclusion}

Ce TP nous a permis de comprendre le processus complet de création d'une image Docker et son déploiement à l'aide de Docker Compose. Nous avons appris à automatiser le lancement d'une application web conteneurisée, ce qui constitue une étape essentielle dans la mise en place d'environnements de développement ou de production modernes.

Les compétences acquises incluent :
\begin{itemize}
    \item La création d'images Docker personnalisées via Dockerfile
    \item L'utilisation de Docker Compose pour l'orchestration
    \item Le déploiement d'applications web dans des conteneurs
    \item La gestion des ports et des services conteneurisés
\end{itemize}
