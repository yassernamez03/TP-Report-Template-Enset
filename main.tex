\section{Introduction}
% ================================================================

Ces TP ont pour objectif de d\'eployer une infrastructure serveur bas\'ee sur
\textbf{Windows Server 2025} et \textbf{Active Directory Domain Services (AD~DS)},
dans un environnement virtualis\'e (VMware / AWS Learner Lab).

\subsection{Promotion en contr\^oleur de domaine}
% ----------------------------------------------------------------

\textit{Notification $\rightarrow$ Promouvoir ce serveur $\rightarrow$ Nouvelle for\^et
$\rightarrow$ \texttt{lab.local} $\rightarrow$ DNS + Catalogue global $\rightarrow$
Mot de passe DSRM $\rightarrow$ Installer}

\begin{alertbox}
Le mot de passe DSRM est indispensable pour la restauration de l'annuaire ---
le conserver imp\'erativement.
\end{alertbox}

\begin{commandbox}
\begin{lstlisting}
Install-ADDSForest `
    -DomainName "lab.local" `
    -DomainNetbiosName "LAB" `
    -ForestMode "WinThreshold" `
    -DomainMode "WinThreshold" `
    -InstallDns -Force
\end{lstlisting}
\end{commandbox}

\subsection{Cr\'eation des Unit\'es d'Organisation (OU)}
% ----------------------------------------------------------------

\textit{ADUC $\rightarrow$ clic droit sur \texttt{lab.local} $\rightarrow$
Nouveau $\rightarrow$ Unit\'e d'organisation}

\begin{commandbox}
\begin{lstlisting}
$base = "DC=lab,DC=local"
foreach ($ou in @("Informatique","RH","Direction")) {
    New-ADOrganizationalUnit -Name $ou -Path $base `
        -ProtectedFromAccidentalDeletion $true
}
\end{lstlisting}
\end{commandbox}

\begin{lstlisting}

    -Members ali.benali, yasser.namez
\end{lstlisting}

\section{Conclusion}
% ================================================================

Ces travaux pratiques ont permis de d\'eployer une infrastructure Active Directory
fonctionnelle. Les comp\'etences acquises couvrent~:

\begin{itemize}
  \item L'installation et la configuration de base de \textbf{Windows Server 2025}.
  \item Le d\'eploiement du r\^ole \textbf{AD DS} et la promotion en contr\^oleur de domaine.
  \item La structuration de l'annuaire via des \textbf{OU}, des \textbf{utilisateurs}
        et des \textbf{groupes de s\'ecurit\'e}.
  \item L'utilisation de \textbf{PowerShell} pour l'automatisation des t\^aches d'administration.
\end{itemize}

Cet environnement servira de base pour les prochains TP (GPO, partage de ressources,
int\'egration de machines clientes au domaine).
