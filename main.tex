\section{Introduction}

Ce laboratoire pratique explore les outils d'analyse des vulnérabilités réseau disponibles dans Kali Linux, notamment \textbf{Nmap} avec ses scripts NSE et \textbf{Greenbone Vulnerability Management (GVM)}. Suite à la détection d'un trafic inhabituel provenant de la machine 10.6.6.23, une analyse approfondie des vulnérabilités a été commandée pour identifier les failles de sécurité potentielles.

\begin{objectifbox}
\begin{itemize}
    \item Effectuer des analyses réseau avec Nmap et ses scripts NSE
    \item Utiliser le script Vulners pour identifier les CVE
    \item Déployer GVM pour une analyse complète des vulnérabilités
    \item Comparer les résultats des deux outils d'analyse
    \item Évaluer les vulnérabilités critiques et proposer des recommandations
\end{itemize}
\end{objectifbox}

\subsection{Environnement de laboratoire}

\begin{itemize}
    \item \textbf{Système d'analyse :} Kali Linux (réseau 10.6.6.0/24)
    \item \textbf{Cible :} Machine suspecte (10.6.6.23 / gravemind.vm)
    \item \textbf{Outils principaux :} Nmap 7.93 avec scripts NSE, GVM
    \item \textbf{Base de données :} CVE et NVD (National Vulnerability Database)
\end{itemize}

\section{Analyse des vulnérabilités avec le script Vulners}

\subsection{Présentation du script Vulners}

\begin{definitionbox}{Script Vulners}
Le script Vulners est un script NSE (Nmap Scripting Engine) qui interroge la base de données Vulners.com pour identifier les vulnérabilités connues (CVE) associées aux services détectés. Il utilise les identifiants CPE (Common Platform Enumeration) pour rechercher des failles de sécurité documentées.
\end{definitionbox}

\subsection{Exécution du scan de vulnérabilités}

Nous lançons maintenant une analyse complète avec le script Vulners en filtrant les CVE ayant un score CVSS d'au moins 4.0.

\begin{commandbox}
\begin{lstlisting}
# Analyse avec le script Vulners (score CVSS >= 4.0)
nmap -sV --script vulners --script-args mincvss=4 10.6.6.23
\end{lstlisting}
\end{commandbox}

\begin{alertbox}
\textbf{Service vulnérable identifié :} OpenSSH 7.9p1
\\
Le service SSH présente plusieurs vulnérabilités exploitables avec des scores CVSS variant de 4.0 à 5.8, incluant des exploits publiquement disponibles.
\end{alertbox}

\section{Partie 2 : Analyse avec Greenbone Vulnerability Management (GVM)}

\subsection{Introduction à GVM}

\begin{definitionbox}{GVM (Greenbone Vulnerability Management)}
GVM est une suite complète de gestion des vulnérabilités open source développée par Greenbone Networks. Contrairement à Nmap qui fonctionne en ligne de commande, GVM offre une interface graphique (Greenbone Security Assistant) pour orchestrer des analyses approfondies et générer des rapports détaillés.
\end{definitionbox}

\subsection{Vérification de l'installation}

Avant de lancer toute analyse, il est crucial de vérifier que GVM est correctement installé et que ses bases de données sont à jour.

\begin{commandbox}
\begin{lstlisting}
# Verification de la configuration GVM
sudo gvm-check-setup
\end{lstlisting}
\end{commandbox}

\begin{resultatbox}
\textbf{État de l'installation :} La commande vérifie que tous les composants nécessaires sont installés et fonctionnels :
\begin{itemize}
    \item OpenVAS Scanner
    \item GVM Daemon (gvmd)
    \item Greenbone Security Assistant (gsad)
    \item Bases de données CVE et SCAP
\end{itemize}

\textbf{Note :} Si des problèmes sont détectés, la commande fournit les instructions pour les résoudre.
\end{resultatbox}

\begin{figure}[H]
    \centering
    \fbox{\includegraphics[width=0.85\textwidth]{screenshot_gvm_check.png}}

\subsection{Démarrage des services GVM}

\subsection{Divergences dans les CVE rapportées}

\begin{alertbox}
\textbf{Constat important :}
\\
Les CVE identifiées par Nmap et GVM ne sont pas identiques. Cette divergence s'explique par :
\begin{itemize}
    \item Des bases de données de vulnérabilités différentes
    \item Des fréquences de mise à jour variables
    \item Des méthodologies de détection distinctes
    \item Des scores de gravité calculés différemment
\end{itemize}

\textbf{Recommandation :} Utiliser les deux outils en complémentarité pour obtenir une vue exhaustive des vulnérabilités.
\end{alertbox}

\section{Conclusion}

Ce laboratoire a permis d'explorer deux approches complémentaires de l'analyse des vulnérabilités réseau. \textbf{Nmap}, avec son script Vulners, offre une solution rapide et efficace pour identifier les CVE associées aux services exposés, particulièrement adaptée aux phases de reconnaissance initiale. \textbf{GVM (Greenbone Vulnerability Management)}, quant à lui, propose une solution d'audit de sécurité plus exhaustive avec une interface graphique facilitant la génération de rapports professionnels.
