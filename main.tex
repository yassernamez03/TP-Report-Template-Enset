\section{Introduction}

Ce travail pratique consiste à déployer un site WordPress complet dans le cloud AWS en utilisant Docker et Docker Compose. WordPress est le système de gestion de contenu (CMS) le plus populaire au monde, utilisé par plus de 40\% des sites web. Nous allons mettre en place une architecture conteneurisée avec WordPress et MySQL, accessible via le port 7070.

\section{Objectifs du TP}

Les objectifs de ce travail pratique sont les suivants :

\begin{itemize}
    \item Créer et configurer une instance EC2 sur AWS
    \item Installer et configurer Docker et Docker Compose
    \item Déployer WordPress et MySQL en conteneurs
    \item Configurer le mapping de ports personnalisé (7070)
    \item Créer un portail WordPress professionnel avec plusieurs pages
    \item Personnaliser le thème et installer des plugins
    \item Gérer les utilisateurs WordPress
\end{itemize}

\subsection{Configuration du fichier docker-compose.yml}

Nous créons le fichier de configuration Docker Compose avec deux services : MySQL et WordPress.

\begin{lstlisting}[language=yaml]
version: "3.8"

services:
  db:
    image: mysql:5.7
    restart: always
    environment:
      MYSQL_DATABASE: wordpress
      MYSQL_USER: wpuser
      MYSQL_PASSWORD: wppassword
      MYSQL_ROOT_PASSWORD: rootpassword
    volumes:
      - db_data:/var/lib/mysql

  wordpress:
    image: wordpress:latest
    restart: always
    ports:
      - "7070:80"
    environment:
      WORDPRESS_DB_HOST: db:3306
      WORDPRESS_DB_USER: wpuser
      WORDPRESS_DB_PASSWORD: wppassword
      WORDPRESS_DB_NAME: wordpress
    volumes:
      - wp_data:/var/www/html

volumes:
  db_data:
  wp_data:
\end{lstlisting}

\section{Conclusion}

Ce travail pratique nous a permis de déployer une solution WordPress complète dans le cloud AWS en utilisant Docker et Docker Compose. Nous avons acquis des compétences importantes en :

\begin{itemize}
    \item Déploiement d'applications web conteneurisées sur AWS EC2
    \item Configuration de Docker Compose pour orchestrer plusieurs services
    \item Gestion du mapping de ports personnalisé
    \item Création et personnalisation d'un site WordPress professionnel
    \item Installation et configuration de thèmes et plugins
    \item Gestion des utilisateurs et des rôles dans WordPress
\end{itemize}

Cette architecture conteneurisée présente plusieurs avantages : portabilité, isolation des services, facilité de déploiement et de mise à jour. Les volumes Docker garantissent la persistance des données (base de données et fichiers WordPress) même en cas de redémarrage des conteneurs.

WordPress, couplé à Docker, offre une solution flexible et scalable pour créer rapidement des sites web professionnels, des blogs, des portfolios ou des sites e-commerce. L'utilisation du cloud AWS permet en outre de bénéficier d'une infrastructure hautement disponible et évolutive.
