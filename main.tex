\section{Introduction}

Ce rapport présente la réalisation de deux travaux pratiques portant sur l'installation et la configuration d'un serveur Windows Server 2025 avec Active Directory. Les manipulations ont été effectuées dans l'environnement cloud AWS Learner Lab.

\begin{objectifbox}
\begin{itemize}
    \item Installer Windows Server 2025 dans une instance EC2
    \item Configurer les paramètres réseau du serveur
    \item Installer le rôle Active Directory Domain Services (AD DS)
    \item Créer une forêt et un domaine Active Directory
    \item Organiser l'annuaire avec des unités d'organisation
    \item Créer des utilisateurs et des groupes
\end{itemize}
\end{objectifbox}

\subsection{Environnement de laboratoire}

\begin{definitionbox}{Technologies utilisées}
\begin{itemize}
    \item \textbf{Plateforme cloud :} AWS Learner Lab
    \item \textbf{Type d'instance :} EC2 t3.medium (4 GB RAM)
    \item \textbf{Système d'exploitation :} Windows Server 2025 Standard Evaluation
    \item \textbf{Stockage :} 50 GB gp3
    \item \textbf{Protocole d'accès :} RDP (Remote Desktop Protocol)
\end{itemize}
\end{definitionbox}

\section{TP 2 : Installation et configuration du rôle Active Directory}

\subsection{Concepts théoriques}

\begin{definitionbox}{Active Directory}
Active Directory est un annuaire LDAP pour les systèmes Windows qui centralise l'authentification et l'administration des ressources. Il permet de gérer les utilisateurs, les ordinateurs, les groupes et les politiques de sécurité de manière centralisée.
\end{definitionbox}

\subsubsection{Modèle Groupe de travail vs Domaine}

\begin{table}[H]
\centering
\begin{tabular}{p{5cm}p{5cm}}
\toprule
\textbf{Groupe de travail} & \textbf{Domaine} \\
\midrule
Base d\'utilisateurs locale (SAM) \& Base centralisée (Active Directory) \\
Pas de gestion centralisée & Administration centralisée \\
Un compte par machine & Un compte pour tout le domaine \\
Adapté pour < 10 postes & Adapté pour les entreprises \\
\bottomrule
\end{tabular}
\caption{Comparaison Groupe de travail / Domaine}
\end{table}

\subsubsection{Structure de l'Active Directory}

L'Active Directory est organisé de manière hiérarchique :

\begin{itemize}
    \item \textbf{Forêt :} Plus haut niveau de l'organisation
    \item \textbf{Domaine :} Limite de sécurité et d'administration
    \item \textbf{Unités d'Organisation (OU) :} Conteneurs pour organiser les objets
    \item \textbf{Objets :} Utilisateurs, ordinateurs, groupes, etc.
\end{itemize}

\subsection{Installation du rôle AD DS}

L'installation du rôle Active Directory Domain Services s'effectue via le Server Manager :

\begin{commandbox}
\begin{lstlisting}
1. Server Manager > Manage > Add Roles and Features
2. Selection du role : Active Directory Domain Services
3. Ajout des fonctionnalites requises
4. Lancement de l'installation
\end{lstlisting}
\end{commandbox}

\begin{figure}[H]
    \centering
