\section{Introduction}

Cette activité s’inscrit dans le cadre du parcours \textbf{AWS Cloud Foundations}.  
Elle vise à découvrir et manipuler le service \textbf{AWS Elastic Beanstalk}, qui permet de déployer et gérer facilement des applications web sans se soucier de la gestion détaillée de l’infrastructure sous-jacente.

Le lab consiste à déployer une application web de démonstration sur un environnement Elastic Beanstalk préconfiguré et à observer les ressources AWS automatiquement créées.

\section{Objectifs de l’activité}

Les objectifs principaux de cette activité sont :

\begin{itemize}
    \item Comprendre le rôle d’AWS Elastic Beanstalk dans le cloud AWS
    \item Déployer une application web sans gestion manuelle des serveurs
    \item Observer les ressources AWS générées automatiquement
    \item Découvrir la gestion et la supervision d’un environnement applicatif
\end{itemize}

\section{Présentation d’AWS Elastic Beanstalk}

AWS Elastic Beanstalk est un service qui simplifie le déploiement et la gestion d’applications web et de services. Il permet aux développeurs de se concentrer sur le code sans gérer l’infrastructure.

\subsection*{Type de service}

\begin{itemize}
    \item \textbf{Type :} PaaS – Platform as a Service
\end{itemize}

\subsection*{Fonctionnalités principales}

\begin{itemize}
    \item Déploiement automatique des applications
    \item Gestion de la mise à l’échelle
    \item Surveillance de l’état de l’application
    \item Intégration avec EC2, ELB, Auto Scaling et CloudWatch
\end{itemize}

\section{Description de l’activité}

L’activité s’est déroulée selon les étapes suivantes :

\begin{enumerate}
    \item Accès à un environnement Elastic Beanstalk déjà créé
    \item Vérification de l’état de santé de l’environnement
    \item Test de l’URL de l’application (erreur 404 attendue)
    \item Déploiement d’une application de démonstration Tomcat
    \item Vérification du bon fonctionnement de l’application
    \item Consultation des paramètres de configuration
    \item Exploration des ressources EC2 associées
\end{enumerate}

\section{Prérequis}

Avant de commencer l’activité, les prérequis suivants sont nécessaires :

\begin{itemize}
    \item Un compte AWS actif (fourni par le lab)

\end{itemize}
